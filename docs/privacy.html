Kendali – Browser MCP: Privacy Policy

Last updated: 7 November 2026

Kendali is a Chrome extension that lets an AI agent running on your own computer control your browser through the Model Context Protocol (MCP). This policy explains what the extension can access and where that data goes.

Summary

  • Kendali has no server, no account, no analytics and no tracking. The developer receives none of your data.
  • The extension communicates only with the Kendali MCP server on 127.0.0.1 (your own machine).
  • It reads or changes a page only when an MCP client you configured asks it to.

What the extension can access

To carry out the commands of your local AI agent, the extension can, on request:

  • Website content: page text, links, form fields, screenshots, console messages and network requests of the tabs it controls;
  • Browsing activity: tab titles and URLs, and browsing history when the agent searches it;
  • Cookies for a site, when the agent lists, sets or removes them;
  • Downloads it starts or monitors, saved to your computer;
  • Data you type or that the agent enters into web forms.

Where the data goes

All of the above is sent only over a WebSocket to ws://127.0.0.1, the Kendali MCP server running on your computer. That server passes the results to the MCP client (AI application) you configured, such as Claude Code, Codex, Gemini CLI, Cursor or OpenCode.

Your AI client may send this data to its model provider (for example Anthropic, OpenAI or Google) as part of the conversation. That transfer is governed by the AI client's and model provider's own privacy policies, not by Kendali. Use Kendali only with AI clients and models you trust.

What is stored

The extension stores only its settings in Chrome's local storage: a random device ID, the browser name you choose and the MCP server port. During a session it also keeps temporary state (its tab group and last-used tab), which is cleared when the browser closes. Screenshots, GIF recordings, PDFs and downloads are saved to your own disk only when the agent asks for them.

Sharing and sale

The developer does not collect, sell, rent or share any user data, and does not use it for advertising, creditworthiness or any purpose other than the extension's single function: letting your local AI agent control your browser.

Security

The local server listens only on 127.0.0.1 and rejects connections from web pages. Pages can contain instructions written to mislead AI agents (prompt injection), so review what your agent does in your logged-in browser.
